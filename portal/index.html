Active Directory Defensive Hardening & Remediation

Enterprise blue team strategies to neutralize the simulated identity attack vectors

Tier-0 Hardening Guide
MITIGATION: KERBEROASTING Priority 1

Group Managed Service Accounts (gMSA)

Transition standard user accounts with registered SPNs to Active Directory Group Managed Service Accounts (gMSA). Windows automatically generates a 128-character complex password and rotates it periodically, rendering offline dictionary cracking mathematically infeasible.

New-ADServiceAccount -Name "gMSA_SQL" -DNSHostName "sql.corp.local" -PrincipalsAllowedToRetrieveManagedPassword "DBA_Servers"
MITIGATION: AS-REP ROASTING Priority 1

Enforce Kerberos Pre-Authentication

Audit the domain for any user accounts where the DONT_REQ_PREAUTH flag is enabled. Disable this property so that an encrypted timestamp (PA-ENC-TIMESTAMP) is strictly required before the KDC returns an AS-REP.

Get-ADUser -Filter {DoesNotRequirePreAuth -eq $true} | Set-ADAccountControl -DoesNotRequirePreAuth $false
MITIGATION: DCSYNC ABUSE Critical Tier-0

Restrict Directory Replication ACEs

Remove DS-Replication-Get-Changes and DS-Replication-Get-Changes-All extended rights from any non-Domain Controller principals or delegated service accounts on the domain root object.

# Enforce strictly to Enterprise Admins, Domain Admins, and Domain Controllers
MITIGATION: LATERAL MOVEMENT Standard Practice

PowerShell CLM & Tiered Administration

Enforce Windows Defender Application Control (WDAC) to restrict interactive user sessions into Constrained Language Mode (CLM), preventing reflective DLL injection and raw Win32 API memory operations.

[Environment]::SetEnvironmentVariable("__PSLockdownPolicy", "4", "Machine")
